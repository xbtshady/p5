# P5 前端重构方案（0.19）

版本：0.19 草案  
最后更新：2026-09-24  
范围：**只动前端（HTML / CSS / JS），后台 `cloudbase.js` 与数据表结构不变。**

---

## 一、为什么要再重构

0.16–0.18 已经把「规格手册感」的基调落到了线上，但对着真实渲染再看，
还有 8 个影响「刷」和「查」的问题没有解决。下面是基于无头 Chrome 实际截图（390px 宽度）的逐项诊断。

| # | 问题 | 当前截图里的表现 | 导致的后果 |
|---|------|----------------|-----------|
| 1 | **探索区喧宾夺主** | 首页首屏被「探索」标题 + 两组维度胶囊 + 「全部 6 组维度」按钮占掉约 180px | 打开 App 第一眼看不到照片，违背「首页是照片流」的定位 |
| 2 | **顶栏操作按钮看不清** | 「＋」和「⋯」是 30×30 白底 + 浅灰边，在 `#fbfaf8` 底色上几乎融入背景 | 用户找不到新增入口，退出这类低频操作反而占了一个常驻图标 |
| 3 | **卡片内文字对齐混乱** | 照片全出血到屏幕边，标题/档位/日期却缩进 18px | 照片像「贴上去的」，文字块像「浮在照片下面」，不像一个整体 |
| 4 | **展开操作区域太小** | 「2 条技巧」开关只有 11px 字 + 4px 内边距 | 单手很难点中，用户可能根本不知道能展开 |
| 5 | **日期与技巧开关抢同一行** | 日期左对齐，「n 条技巧」右对齐，两者信息量不对等却并排 | 视觉重心分散，用户不知道点哪里 |
| 6 | **新增页像设置面板** | 6 组维度胶囊垂直铺开，占满整个屏幕 | 录入一张照片像在填一份长问卷，心理负担大 |
| 7 | **保存按钮淹没在长表单里** | 保存按钮在最底部，前面是 AI 提示词、档位、tips | 用户要滑到底才能保存，打断「快记」节奏 |
| 8 | **整体缺少「参考手册」的秩序感** | 只有字号和灰度区分，没有明确的「页眉 / 章节 / 条目」层级 | 看起来像一个普通笔记 App，不像能查资料的手册 |

核心结论：**0.18 完成了「去灰去磨砂」，但还没完成「把参考手册的信息结构做出来」。**

---

## 二、重构目标

不推翻 0.18 的基调（暖白纸色、中性色、照片唯一彩色、小圆角），只重新组织信息。

1. **首页默认只看照片** —— 把「探索」从常驻区移走，需要查的时候一步展开。
2. **单手操作优先** —— 所有可交互元素最小 40×40 CSS px，文字按钮不小于 13px。
3. **卡片像一张索引卡** —— 照片 + 标题 + 元信息 + 可展开详情，四个区域边界清楚。
4. **新增页像填一张卡片，不像填一份问卷** —— 分组、可折叠、保存触手可及。
5. **保持无构建、无新依赖** —— 继续用 Vue 3 CDN + Vant 4 + 原生 CSS。

## 三、信息架构与布局方案

### 3.1 首页：把「探索」收进顶栏抽屉

```
┌──────────────────────┐
│ P5        ＋   筛选   ⋯ │   ← 顶栏：新增、筛选、更多（退出）
├──────────────────────┤
│                      │
│        照片 1        │
│                      │
│ 标题                 │
│ 中长焦 · 逆光 · 黄昏   │
│ 2026.09.21  ·  2 条  │   ← 点整行展开
│                      │
│        照片 2        │
│                      │
└──────────────────────┘
```

**改动点：**

- 移除首页顶部常驻的「探索」面板。
- 顶栏右侧三个动作：「＋」（新增）、「筛选」（漏斗图标）、「⋯」（退出）。
- 点击「筛选」后，从顶栏下方滑下一个全宽筛选面板（不是新页），面板内包含原来的维度分组 + 清除按钮 + 关闭按钮。
- 面板关闭后，首页回到纯照片流。
- 有筛选生效时，顶栏「筛选」图标加一个小红点或文字徽标；同时 feed 顶部出现一行「只看 中长焦 + 逆光  ·  清除」的提示条。

**为什么这样：**

- 用户 80% 的访问可能是「刷最近的照片」，不应该每次都被探索区顶到首屏外。
- 查参考时，筛选是一个明确的「进入搜索模式」动作，抽屉面板能提供足够空间。
- 不引入新路由或新页面，纯前端状态切换，后台不用改。

### 3.2 照片卡片：做成「索引卡」

```
┌──────────────────────┐
│                      │
│        照片          │   ← 全出血保留
│                      │
├──────────────────────┤
│ 地铁口的逆光侧脸      │   ← 标题 16px / 500
│ 中长焦 · 逆光 · 黄昏  │   ← 档位 13px / muted
│ 2026.09.21   ·   查看 │   ← 日期 + 展开触发，整行可点
├──────────────────────┤   ← 展开后：上边框 1px 细节线
│ 描述                 │
│ 镜头：中长焦          │
│ 光线：逆光            │
│ - 让人物偏离中心...   │
│ - 按人脸测光...       │
└──────────────────────┘
```

**改动点：**

- 照片仍然全出血，但卡片下方的信息区也改为**全宽白底块**，和照片之间用 1px 细节线分开（或者照片底部直接压住白底块，类似杂志 caption）。
- 标题、档位、日期行统一左对齐到 16px（或 18px）内边距，不再出现「照片到边、文字缩进」的错位。
- **展开触发区做成整行可点**（日期 +「查看 / 收起」），而不是只有一个 11px 小按钮。最小点击高度 40px。
- 展开后内容用 1px 细节线与默认区隔开，而不是目前的 `padding-top` 留白。
- 删除按钮从照片右上角移到底部操作行，或者保留但加大到 36×36 并提升对比。
- 卡片间距从 38px 缩小到 28px，让 feed 更紧凑；卡片之间用 1px 细节线或者纯留白区分，二选一。

**保留不变：**

- 不做详情页。
- 技巧默认收起，默认态档位只显示值。
- 不确定档位不上卡片。

### 3.3 新增页：分组 + 可折叠 + 底部固定保存

```
┌──────────────────────┐
│ ←  P5                │
├──────────────────────┤
│ 照片                 │
│ [   上传占位   ]     │
│                      │
│ 标题 / 描述          │   ← 可折叠组（默认展开）
│ [生成提示词][粘贴回填]│
│                      │
│ 档位           [展开]│   ← 可折叠组（默认折叠）
│                      │
│ AI 技巧        [展开]│   ← 可折叠组（默认折叠）
│                      │
│ ┌──────────────────┐ │
│ │      保 存       │ │   ← 底部固定保存条
│ └──────────────────┘ │
└──────────────────────┘
```

**改动点：**

- 页面拆成 3 个可折叠分组：
  1. **基本信息**（照片、标题、描述）—— 默认展开；
  2. **档位**（AI 回填/手选维度）—— 默认折叠，点击展开；
  3. **AI 技巧** —— 默认折叠，点击展开。
- 折叠组头部显示当前已选摘要，例如「档位：中长焦 / 逆光 / 侧身」，让用户不用展开也知道填了什么。
- 档位组内，**单选维度用 Vant `van-picker` 或 `van-popup` 弹层选择**，不再把所有胶囊平铺出来；只有多选维度（姿势）和 AI 追加维度保留胶囊。
  - 理由：镜头/时段/光线/视角/景别这 5 个维度每次只能选一个值，弹层选择比扫一堆胶囊快得多。
- AI 提示词 / 粘贴回填 两个按钮放在基本信息组底部，而不是顶栏下面。
- 保存按钮固定在底部工具栏（sticky footer），不随表单滚动消失。
- 返回按钮从文字改成左箭头图标，与 iOS/Android 惯例一致。

**保留不变：**

- 仍然不走 AI 直连，仍然用剪贴板中转。
- 维度值仍然只能从字典/池子挑，不给自由输入。

### 3.4 登录页：居中卡片保留，增强品牌

- 保持居中卡片布局，这是登录页最合适的结构。
- 品牌区「P5」字号从 20px 稍微放大并加字距，让它一眼就是这个应用。
- 输入框标签从占位符式改成顶部小标签（floating label 或固定小标签），提升可读性。
- 登录按钮保持主色填满，不再用 Vant 默认样式。

### 3.5 顶栏统一处理

三页共用 `.topbar`，但内容不同：

| 页面 | 左侧 | 中间 | 右侧 |
|------|------|------|------|
| 首页 | （无，P5 可居中或左对齐） | P5 | ＋、筛选、⋯ |
| 新增 | ← 返回图标 | P5 | （空） |
| 登录 | （无） | P5 | （空） |

- **动作按钮全部填充/加深**：
  - 「＋」做成 32×32 近黑底 + 白字「＋」，高对比。
  - 「筛选」用图标 + 文字（或纯图标），当前有筛选时显示红点/徽标。
  - 「⋯」改成头像/菜单图标，打开后是「退出登录」。
- 顶栏滚动后仍保留 1px 下边界，但可以考虑在首页默认态下边界隐藏，滚动才出现（目前已经是这样）。

## 四、视觉与排印规范（细化，不推翻）

### 4.1 颜色：继续用 0.18 这套

```css
--bg: #fbfaf8;
--card: #ffffff;
--text: #17181a;
--muted: #6b6f76;
--accent: #17181a;
--danger: #b3382a;
--border: var(--ink-10);
```

颜色足够，不需要引入新彩色。重点是**用法**改变：

- 卡片/面板用 `--card` 纯白，和 `--bg` 纸白形成层；
- 分隔用 `--border` 1px 细节线；
- 主操作按钮用 `--accent` 填满；
- 文字按钮/图标默认 `--text`，hover 用 `--muted` 背景。

### 4.2 字号与字重

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 品牌 | 20px | 500 | 顶栏 P5 / 登录页品牌 |
| 标题 | 16px | 500 | 卡片标题、分组标题 |
| 正文 | 14px | 400 | 描述、tips、输入文字 |
| 元信息 | 12px | 400 | 日期、档位行 |
| 小节标签 | 11px | 500 | 维度组名、计数 |

**改动：**

- 卡片描述从 13px 提到 14px，可读性更好。
- 日期和档位明确用 12px，和 16px 标题拉开。
- 小节标签 11px 保留，但加字距。

### 4.3 间距系统

把目前散落的间距收进几个变量：

```css
--gutter: 16px;          /* 页面左右留白 */
--section-gap: 32px;     /* 分组之间 */
--card-gap: 24px;        /* 卡片之间 */
--touch-min: 44px;       /* 可点区域最小高度 */
```

首页卡片之间 24px，不再用 38px。

### 4.4 圆角

- 按钮 / 胶囊：6px
- 卡片 / 面板：8px
- 输入框：6px
- 顶部抽屉面板：底部圆角 12px（滑出感）

### 4.5 动效

- 筛选抽屉滑入：200ms ease-out；
- 折叠组展开：高度 200ms，内容淡入 150ms；
- 卡片展开：不位移，只展开内容，避免列表跳动；
- 保持 `prefers-reduced-motion` 尊重。

## 五、关键交互细节

### 5.1 筛选抽屉

- 默认收起；点击顶栏「筛选」后从顶栏下方滑出，覆盖内容区上半部分或全屏。
- 抽屉内分组与当前 0.15 一致：基础维度在前，AI 追加维度在后。
- 抽屉关闭按钮放在抽屉顶部右侧，同时点遮罩或按 Esc 关闭。
- 有筛选生效时，feed 顶部出现一行「只看 …  ·  清除」提示条，点击清除关闭筛选并隐藏提示条。
- 维度内单选、跨维度叠加的语义保持 0.15 不变。

### 5.2 卡片展开

- 默认态：标题 + 档位行 + 日期行（整行可点）。
- 展开后：显示描述 + 完整档位（维度名:值）+ tips 列表。
- 再次点击同一行或「收起」收回。
- 保留键盘可访问（Enter 展开）。

### 5.3 新增页折叠组

- 每个折叠组头部有：标题 + 当前摘要 + 展开/收起箭头。
- 摘要示例：
  - 基本信息：「照片 · 地铁口的逆光侧脸」或「未填写标题」
  - 档位：「中长焦 / 逆光 / 侧身」
  - AI 技巧：「2 条」
- 折叠组切换不丢失已填内容。

### 5.4 删除照片

- 从照片右上角移到卡片底部操作行（与展开区相邻），或者保留在照片右上角但加大/加深。
- 删除前仍弹 Vant 确认框。

## 六、实施计划

按「数据层不动 → 结构层 → 视觉层」的顺序，切成 3 个小版本。

| 版本 | 内容 | 文件 |
|------|------|------|
| 0.19a | 首页探索区改抽屉；顶栏按钮加对比 | `index.html`, `js/app.js`, `css/style.css` |
| 0.19b | 卡片改成索引卡结构；展开区整行可点；卡片间距收紧 | `index.html`, `js/app.js`, `css/style.css` |
| 0.19c | 新增页折叠分组 + 单选维度用弹层 + 底部固定保存条 | `create.html`, `js/create.js`, `css/style.css` |

每版单独验证：

1. 跑 `node js/facets.test.js`；
2. 无头 Chrome 量 320/360/430 三档，确认 `ovf === 0`、可点元素最小高度 ≥ 40px、
   筛选抽屉开合正常、卡片展开/收起正常；
3. 真实截图看一眼（尤其顶栏对比度和卡片新结构）。

## 七、验收标准

- 首页默认态下，用户不滚动就能看到至少一张照片的主体（探索区不再占首屏）。
- 所有可交互区域最小 40×40 CSS px（按钮、行触发区）。
- 320px 宽度下无横向溢出（`scrollWidth - clientWidth === 0`）。
- 筛选语义保持 0.15：维度内单选、跨维度叠加、再点取消。
- 新增页从选完照片到保存，拇指操作路径不超过 3 屏滚动。
- 颜色仍只有 0.18 的 `:root` 一套，无新硬编码。

## 八、明确不做

避免这次重构又做宽：

- **不改 1.0 搜索**：搜索仍是独立版本。
- **不改详情页逻辑**：仍然点照片全屏看图，不做独立详情页。
- **不改后台**：`cloudbase.js`、数据库表、RLS 都不动。
- **不改维度字典**：基础维度 6 个、值域、`js/facets.js` 不变。
- **不改 AI 闭环**：仍然剪贴板中转，不站内接 AI。
- **不引入新依赖**：继续无构建，不引入 Tailwind/Preline 等。

## 九、参考站点（保持）

视觉方向仍按 0.16 定下的方向走：

- **note.com** —— 信息流与排版层次；
- **器材规格页** —— 「标签 / 值」秩序；
- **Takram** —— 留白与字号层级。

这次重构不是再换风格，而是把同一个方向的信息结构做扎实。
